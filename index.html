How to use this library

  1. Start with Phase 1 for 1–2 weeks.
  2. Choose 5–7 poses per session (not all at once).
  3. Click each pose for step-by-step instructions + notes.
  4. Use “Preparation Poses” if a pose feels tight or difficult.
